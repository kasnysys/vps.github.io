# happ · автообновляемая подписка

VLESS + Reality подписка для [Happ](https://happ.su) (Xray-core).
Конфиги не лежат в репозитории — их собирает Cloudflare Worker из публичных
коллекторов и отдаёт только по ключу.

## Как это работает

```
публичные коллекторы (обновляются каждый день)
        │
        ▼
Cloudflare Worker — тянет, парсит, определяет страну по IP
        │
        ▼
JSON с серверами: 🇩🇪 Germany #1 … 🇺🇸 United States #20
        │
        ▼
Happ → Подписки → «+» → Ссылка
```

- Воркер пересобирает список раз в 15 минут, ничего вручную делать не нужно.
- Определяет страну по IP (встроенная таблица + дозапрос через api.country.is).
- Из каждой страны берёт ровно **20** серверов, страны с меньшим количеством пропускает.
- В каждый конфиг зашит обход `.ru` / `.su` / `.рф` напрямую и блок рекламы.
- Отдаёт данные только с `?key=...` — без ключа `403 Forbidden`.

Текущий результат: 11 стран × 20 = 220 серверов.

## Подключение

Ссылка подписки (ключ подставить свой):

```
https://<worker>.workers.dev/?key=<KEY>
```

Happ → **Подписки** → «+» → **Ссылка** → вставить → «Обновить».

Страница со списком: https://kasnysys.github.io/vps.github.io/

## Настройки воркера

В начале `worker.js`:

| Константа | Что делает | По умолчанию |
|---|---|---|
| `PER_COUNTRY` | серверов из каждой страны | 20 |
| `MIN_PER_COUNTRY` | минимум серверов, иначе страна пропускается | 20 |
| `CACHE_TTL` | сколько секунд держать готовый ответ | 900 |
| `LIVE_GEO_LIMIT` | максимум гео-запросов за прогон | 20 |
| `SOURCES` | откуда тянуть конфиги | barry-far, MhdiTaheri |

## Безопасность

- Ключи серверов не публикуются: в репозитории только страница и этот README.
- Доступ — по `?key=`. Ключ виден в URL, иначе Happ не умеет, так что не раздавай ссылку.
- Публичные конфиги — чужие серверы: скорость и живучесть не гарантированы.
