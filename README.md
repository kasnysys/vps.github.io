# happ vless configs

Конфиги для [Happ](https://happ.su) (Xray-core), серверы VLESS + Reality.

## Файлы

- `vless.json` — массив из трёх конфигов (Нидерланды, Финляндия, Швейцария). В каждом уже настроен обход: `.ru`, `.su`, `.рф`/`.xn--p1ai`, `geosite:ru`, `geoip:ru` и локальные сети идут напрямую, остальное — через прокси.
- `links.txt` — те же серверы в виде `vless://` ссылок, для импорта по ссылке.

## Как импортировать

**Ссылкой (проще всего):**
1. Открыть `links.txt`, скопировать нужную строку `vless://...`
2. Happ → «+» → «Импорт из буфера обмена»

**JSON-конфигом:**
1. Скачать `vless.json`
2. Happ → «+» → «Импорт из файла»

Если Happ ругается на массив — берите по одному объекту из `vless.json` (файл можно открыть любым текстовым редактором и скопировать нужный блок `{ ... }`).

## Что значит «не юзать для .ru»

В `routing.rules` есть правило с `outboundTag: "direct"` для российских доменов и IP. Российские сайты открываются напрямую с твоего IP, остальное — через VPN. Правило стоит выше остальных, поэтому срабатывает первым.

> Внимание: в конфигах лежат реальные ключи (id/publicKey). Если репозиторий публичный — доступ к серверам получит любой, кто их увидит.
