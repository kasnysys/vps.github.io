# happ · автообновляемая подписка

VLESS + Reality подписка для [Happ](https://happ.su) (Xray-core).
Список серверов обновляется сам — GitHub Action раз в 6 часов собирает свежие
конфиги из публичных коллекторов, определяет страну и перезаписывает `vless.json`.

## Как это работает

```
публичные коллекторы конфигов
        │  GitHub Action, каждые 6 часов
        ▼
tools/build_sub.py — парсит vless://, страна по IP, 20 серверов на страну
        │
        ▼
vless.json → GitHub Pages
        │
        ▼
Happ → Подписки → «Обновить»
```

- Только `vless` + `security=reality` + `tcp`, мусор и дубликаты отбрасываются.
- **Каждый сервер пингуется**: TCP-коннект + TLS-рукопожатие с его SNI, таймаут 5 с.
  Мёртвые отбрасываются, живые сортируются по пингу.
- Страна определяется по IP (ip-api.com), имя вида `🇩🇪 Germany #1`.
- Из каждой страны берутся **20 самых быстрых** (первые по пингу). Если стран
  с 20 живыми меньше шести, порог снижается до 3 — чтобы список не остался пустым.
- В каждый конфиг зашит обход `.ru` / `.su` / `.рф` напрямую и блок рекламы.
- Если сборка получилась меньше 20 серверов — файл не перезаписывается.

Сейчас: 19 стран, **160 живых серверов** (из 975 проверенных выжило 274).

## Подписка

```
https://kasnysys.github.io/vps.github.io/vless.json
```

Happ → **Подписки** → «+» → **Ссылка** → вставить → «Обновить».

Страница со списком: https://kasnysys.github.io/vps.github.io/

Файл напрямую с GitHub, если Pages капризничает:

```
https://raw.githubusercontent.com/kasnysys/vps.github.io/main/vless.json
```

## Настройки

`tools/build_sub.py`:

| Константа | Что делает | По умолчанию |
|---|---|---|
| `PER_COUNTRY` | серверов из каждой страны (самые быстрые) | 20 |
| `MIN_PER_COUNTRY` | минимум живых, иначе страна пропускается | 20 |
| `PROBE_TIMEOUT` | таймаут пинга, секунд | 5 |
| `PROBE_WORKERS` | параллельных проверок | 64 |
| `SOURCES` | откуда тянуть конфиги | barry-far, MhdiTaheri |

Расписание — `.github/workflows/update.yml`, строка `cron: "17 */6 * * *"`.
Запустить вручную: вкладка **Actions** → **update subscription** → **Run workflow**.

## Файлы

- `vless.json` — готовые конфиги Xray, их и ест Happ.
- `index.html` — страница: читает `vless.json`, показывает серверы, кнопки «JSON».
- `tools/build_sub.py` — сборщик.
- `.github/workflows/update.yml` — крон.

> Серверы здесь — публичные бесплатные конфиги из открытых коллекторов.
> Скорость и стабильность не гарантированы, зато список не заканчивается.
> Ключи видны всем, кто откроет `vless.json`: это чужие серверы, не твои.
