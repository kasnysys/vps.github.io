# happ · автообновляемая подписка с автовыбором сервера

VLESS + Reality подписка для [Happ](https://happ.su) (Xray-core).
Список серверов обновляется сам — GitHub Action раз в 6 часов собирает свежие
конфиги из публичных коллекторов, определяет страну и перезаписывает `vless.json`.

**Главное:** серверы пингует не GitHub, а сам Xray у тебя на телефоне.
Внутри каждого профиля лежит `observatory` + `leastPing`: Xray раз в минуту
проверяет все серверы со **твоего** устройства и ходит через самый быстрый.
Провайдер у тебя свой — значит и выбор свой, а не «усреднённый из США».

## Как это работает

```
публичные коллекторы конфигов
        │  GitHub Action, каждые 6 часов (только сборка, без пинга)
        ▼
tools/build_sub.py — парсит vless://, страна по IP, 20 серверов на страну
        │
        ▼
vless.json → GitHub Pages  (31 профиль)
        │
        ▼
Happ → Подписки → «Обновить» → профиль «🌍 Авто — лучший сервер»
        │
        ▼
Xray на телефоне пингует все серверы (observatory) и выбирает leastPing
```

- Только `vless` + `security=reality` + `tcp`, мусор и дубликаты отбрасываются.
- Страна определяется по IP (ip-api.com), имя вида `🇩🇪 Germany #1`.
- Из каждой страны берётся до **20** серверов; страны с менее чем 3 серверами пропускаются.
- **Никакого пинга на GitHub** — серверы не фильтруются по ответу из дата-центра.
- В каждый конфиг зашит обход `.ru` / `.su` / `.рф` напрямую и блок рекламы.
- Если сборка получилась пустой — файл не перезаписывается.

## Профили в подписке

- `🌍 Авто — лучший сервер` — **основной**, все серверы всех стран в одном профиле,
  Xray сам выбирает самый быстрый с твоего телефона.
- `🇩🇪 Germany — авто`, `🇳🇱 Netherlands — авто`, … — по одному профилю на страну,
  там автовыбор только внутри страны. Удобно, если хочешь именно Нидерланды.

Сейчас: 31 профиль, в общем авто-профиле ~335 серверов из 30 стран.

## Подписка

```
https://kasnysys.github.io/vps.github.io/vless.json
```

Happ → **Подписки** → «+» → **Ссылка** → вставить → «Обновить».

Первый профиль в списке — `🌍 Авто — лучший сервер`, его и включай.

Страница со списком: https://kasnysys.github.io/vps.github.io/

Файл напрямую с GitHub, если Pages капризничает:

```
https://raw.githubusercontent.com/kasnysys/vps.github.io/main/vless.json
```

## Настройки

`tools/build_sub.py`:

| Константа | Что делает | По умолчанию |
|---|---|---|
| `PER_COUNTRY` | серверов из каждой страны в профиль | 20 |
| `MIN_PER_COUNTRY` | минимум серверов, иначе страну пропускаем | 3 |
| `PROBE_URL` | URL, которым Xray пингует серверы с клиента | google generate_204 |
| `PROBE_INTERVAL` | как часто перепинговать | 1m |
| `PER_COUNTRY_PROFILES` | делать отдельные профили на страны | True |
| `SOURCES` | откуда тянуть конфиги | barry-far, MhdiTaheri |

Расписание — `.github/workflows/update.yml`, строка `cron: "17 */6 * * *"`.
Запустить вручную: вкладка **Actions** → **update subscription** → **Run workflow**.

## Файлы

- `vless.json` — готовые конфиги Xray, их и ест Happ.
- `index.html` — страница: читает `vless.json`, показывает профили, кнопки «JSON».
- `tools/build_sub.py` — сборщик.
- `.github/workflows/update.yml` — крон.

> Серверы здесь — публичные бесплатные конфиги из открытых коллекторов.
> Скорость и стабильность не гарантированы, зато список не заканчивается.
> Ключи видны всем, кто откроет `vless.json`: это чужие серверы, не твои.
