Как подключить

  1. Скопируй ссылку подписки выше.
  2. Happ → Подписки → «+» → Ссылка.
  3. Вставить, сохранить, «Обновить».
  4. Появятся 3 сервера — выбирай любой.

Не ест json по ссылке — скачай vless.json и импортируй файлом: Happ → «+» → Из файла. Или жми JSON у сервера и вставляй из буфера.

Внутри json лежат ключи серверов. Кто получит ссылку — сможет подключиться. Не раздавай зря.
